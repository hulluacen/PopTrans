# 本地术语库 — v1.4.1

点击主界面顶部的“术语库”，在独立窗口中管理词条。设置页只保留程序设置。
左侧“本地术语库”固定置顶，保留旧版词条，不能重命名或删除整个库。
可新建、重命名、删除其他词库，并分别勾选启用；勾选状态保存后生效。总开关可暂停全部术语参考，同时保留各库的选择。
点击词库名称切换编辑对象。切换不会丢失草稿；“保存词库”保存全部库的修改。
导入只追加到当前选中的库，CSV 导出也仅包含当前库。
跨库出现相同原词和语言方向时，启用的本地词条优先；同一库内的多个含义保留。关闭本地库后，其他启用库的同词条可参与翻译。
表格有三列：原词、参考译法、适用语境（可选）。语言方向在顶部切换，支持英译中和中译英。
同一个原词可以占多行，例如 web 可以分别填写“膜材”和“网页”，在第三列说明对应语境。
建议填写一个首选译法，含义说明具体用途，例如“张力控制设备”，避免只写“专业术语”。
大小写不影响英文匹配；Dancer 与 dancer 无需重复添加。
本版使用原版翻译主提示和纯文本生成，术语不采用模型 JSON 输入输出或强制 JSON 格式。
术语、适用语境和命名词库的领域标签通过独立的系统消息提供，待译正文单独发送；备注按描述数据处理。
匹配时较长词组优先以避免重叠，提供给模型时按原文中实际出现次序排列。
检测到明显规则混入或术语模式输出截断时会提示重试，失败结果不写入缓存；不对译文做术语替换。
不执行译后强制替换，模型仍可能判断错误；重要内容请人工复核。

直接点击单元格编辑，Tab 切换单元格，Enter 向下继续。支持搜索、批量删除、撤销和重做。
可以从 Excel 复制两列或三列，也可以导入 CSV / TSV；追加前先预览，完全重复的记录跳过，同词不同含义保留。
CSV 导出包含所有语言方向，可以用于备份、整理后重新导入。仅支持 UTF-8 文本文件。
保存词库后，下次翻译生效，无需重新加载模型；关闭未保存的窗口会提示处理修改。
主界面的“术语开／关”控制是否参考词库。其他窗口修改了词库时，旧草稿会提示保存冲突，保留草稿供核对后重新载入。

翻译完成后可展开“本次提供的术语参考”，查看发送给模型的候选；该记录不代表模型实际采用。
仅匹配当前文字的词进入提示词，英文按完整词或短语匹配，优先较长短语。
同一原词的候选一起保留；如果整组超过长度上限则整组略过，不因为排列靠前就只使用第一个含义。
每块最多 12 组、合计约 256 个估算 token 的参考。记录会提示因上限未提供的组数。
术语文件未修改时复用内存词库；保存后翻译缓存随版本更新。

每库最多 3000 条，全部库合计最多 12000 条；最多 32 个附加库。原词和译法各最多 80 字，语境最多 160 字；整个词库文件和导入文件各最多 2 MB。
全部词库和启用状态保存在程序目录的 glossary.json，可整体备份；示例默认关闭，可自由编辑或删除。
术语数据随翻译交给本机模型处理，不发送到外部服务；代码版本管理与发行包默认排除该文件。

本版参考[沉浸式翻译公开的 AI Prompt 配置方式](https://immersivetranslate.com/zh-Hans/docs/prompts/)和[领域语境说明](https://immersivetranslate.com/zh-Hans/docs/advanced/)，根据本地翻译模型适配。

已知限制：跨领域混合文本、指令式语境备注仍可能引起误用。本地 1.8B 模型尚未通过通用术语能力验证，本版用于对照评估，不能据此认定所有语境和句法都已稳定。
