# 本地术语参考测试版

打开设置顶部的“本地术语参考”，填写当前领域、原词、参考译法和适用语境。
启用开关后点击“保存术语表”，下次翻译立即生效，无需重新加载模型。
示例默认关闭，可编辑或删除；第一版支持英译中、中译英。

“西门子／卷绕”示例中，`web` 可参考膜材、连续料带，`winder` 可参考卷绕装置、收卷机。
适用语境可以注明例外，例如网页、网络场景下采用其他含义。
这些条目仅为模型提供参考，保留结合上下文调整含义和语法的自由，不执行译后替换。
模型仍有可能误用术语，重要内容请人工检查。

仅当前文本匹配的词进入提示词，优先较长词组；英文按完整词或短语匹配。
每块最多提供 12 条、合计最多约 256 个估算 token 的参考，避免挤占正文。
术语文件未修改时复用内存词库；保存后原翻译缓存不再用于新版本术语表。

数据保存在程序目录下的 `glossary.json`，可以单独备份。
术语数据不会联网发送；代码版本管理与发行包默认排除该文件。
